# NoAIOptimus v1.0

Лёгкая консольная утилита (пока) для быстрого просмотра состояния ПК, накопителей и автозагрузки.

> ⚠️ **ЗАПУСКАТЬ ОТ ИМЕНИ АДМИНИСТРАТОРА**

### Текущие функции:
1. **Контроль автозагрузок** — детект всех существующих программ в автозагрузке (для полного доступа нужен запуск от имени администратора).
2. **Анализ дисков** — показывает файловую систему, общий объём и остаток свободного места.
3. **Мониторинг скорости диска `C:`** — отслеживание скорости чтения и записи в реальном времени.
4. **Температура и здоровье накопителей** — отслеживается нагрев SSD/HDD и оставшийся ресурс жизни накопителя.

### Управление:
* `Space` (Пробел) — переключение между экранами.

### Установка и запуск:
1. Перейдите в раздел **[Releases](../../releases)** справа.
2. Скачайте файл `NoAIOptimus.v1.0.exe` (он полностью автономный и не требует установки .NET).
3. Запустите файл **от имени администратора** (чтобы утилита считала все программы в автозагрузке и температуру датчиков).

### Стек:
* **Язык:** C# / .NET 8 (Windows)
* **Библиотеки и API:** `LibreHardwareMonitorLib`, `System.Management` (WMI), `PerformanceCounter`, WinAPI (`kernel32.dll` для поддержки ANSI-цветов).
